# Folio MVP

개인 커리어 데이터부터 공고 분석, 지원 관리, 자기소개서 초안, 면접 준비까지 연결하는 개인용 취업 워크스페이스의 첫 번째 MVP입니다.

## 실행

Node.js가 설치된 환경에서:

```powershell
npm.cmd start
```

브라우저에서 `http://localhost:4173`을 엽니다. 별도의 의존성 설치는 필요 없습니다.

`index.html`을 직접 열어도 대부분의 기능을 사용할 수 있습니다.

## 포함된 기능

- 홈 대시보드와 할 일 체크
- 커리어 경험 등록
- 채용 공고 본문 등록 및 키워드 분석
- 저장된 경험과 공고 요구사항 매칭
- 칸반 형태의 지원 상태 관리
- 커리어 근거 기반 자기소개서 초안 생성 및 자동 저장
- 면접 일정과 준비 현황
- 브라우저 `localStorage` 데이터 보존

## 현재 범위

이 버전은 백엔드나 외부 AI API 없이 제품의 핵심 사용자 흐름을 검증하기 위한 로컬 MVP입니다. 분석 및 문서 초안은 브라우저 내부 규칙 기반으로 동작합니다. 다음 단계에서 인증, PostgreSQL, 실제 LLM 기반 구조화 출력, 공고 URL 수집을 연결할 수 있습니다.
